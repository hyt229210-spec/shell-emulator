# Shell Emulator — Вариант 4

## Общее описание
GUI-эмулятор командной строки UNIX-подобной ОС на Python (Tkinter).
Виртуальная файловая система (VFS) загружается из ZIP-архива и работает
целиком в памяти — сам архив не распаковывается и не изменяется на диске.
Поддерживается настройка через параметры командной строки и
XML-конфигурационный файл, а также выполнение стартовых скриптов.

## Функции и настройки

### Команды
- `ls [путь]` — список содержимого каталога VFS (текущего или указанного)
- `cd <путь>` — смена текущего каталога (поддерживает `..`, `.`, вложенные пути)
- `clear` — очистка окна вывода
- `tail <файл> [N]` — последние N строк файла (по умолчанию 10)
- `who` — информация о текущем сеансе
- `cp <откуда> <куда>` — копирование файла внутри VFS (в памяти)
- `exit` — завершение работы

### Параметры запуска
| Параметр   | Описание                            |
|------------|--------------------------------------|
| `--vfs`    | путь к ZIP-архиву VFS                |
| `--script` | путь к стартовому скрипту            |
| `--config` | путь к XML-конфигурационному файлу   |

Если параметр задан и в конфиге, и в командной строке — побеждает конфиг
(пример: `config.example.xml`).

Стартовый скрипт выполняется построчно; строки с `#` — комментарии;
ошибочные строки не прерывают выполнение остальных команд.

## Сборка и тесты
Требуется Python 3 (используется только стандартная библиотека, Tkinter
входит в комплект).

Генерация тестовых VFS-архивов (создаются локально, не хранятся в репозитории):
\`\`\`
python tests/make_vfs.py
\`\`\`

Запуск эмулятора:
\`\`\`
run.bat --vfs tests/generated_vfs/minimal.zip
\`\`\`
или напрямую:
\`\`\`
python src/main.py --vfs tests/generated_vfs/deep.zip --script scripts/stage5_script.txt
\`\`\`

Сценарии проверки по этапам — в папке `scripts/` (`test_stage4.bat`, `test_stage5.bat` и т.д.).

## Примеры использования
\`\`\`
$ python src/main.py --vfs tests/generated_vfs/deep.zip
deep:/> ls
level1
deep:/> cd level1/level2/level3
deep:/level1/level2/level3> ls
deep_file.txt
deep:/level1/level2/level3> tail deep_file.txt
Файл на 3 уровне
deep:/level1/level2/level3> cd ../../..
deep:/> cp level1/top_file.txt copy.txt
Скопировано: /level1/top_file.txt -> /copy.txt
deep:/> exit
\`\`\`
